# Netzwerkprotokoll (Stand 11.05.2025)
Das folgende Dokument gibt eine Übersicht über jeden schon implementierten Netzwerkbefehl und wird für jeden neuen Befehl aktualisiert. Befehle haben die Struktur:

```
befehl param1 param2 … paramN
```

Der Befehl und die Parameter werden jeweils mit einem Leerschlag voneinander getrennt. Bei den `chatAll`, `chatTo` und `chatLobby`-Befehlen werden die letzten `N - 2` Parameter als Nachricht interpretiert, auch wenn es in der Tabelle nur als einen Parameter dargestellt wird.
